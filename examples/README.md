# 示例流程包

`示例流程包.zip` = 流程包格式的可运行演示（一图 + 两节点：等模板 → 点模板）。

导入方法：启动程序 → 工作台「编流程」页 → 流程列表下方「导入」按钮（或列表
空白处右键「导入流程包」）→ 选本 zip。导入后流程「演示·等图点图」出现在列表，
模板「按钮_开始」进「示例」库。

注意：包里模板是**程序画的几何图**，不会在任何真实游戏画面上命中——它只演示
包的结构与导入链路。真实用途 = 自己在工作台框选采集模板、编排流程后，用
「导出」按钮打成 zip 传给装同款软件的另一台机器。

zip 内部结构（给 AI/脚本生成流程包参考）：

```text
flows.json            包标记 kind="emuhive-flow-pack" + custom_flows/
                      flow_categories/flow_category_order 三键
templates/index.json  被引用模板的账本子集（格式同程序内账本）
templates/示例/*.png  图片实体（目录名 = 账本 category）
```
